# 0004. Лицензия Core в Directus 12 и модель прав

- Статус: **требует решения владельца** (фаза 0, 2026-10-28)

## Контекст

В Directus 12.5.1 без лицензионного ключа действует `DIRECTUS_CORE_LICENSE` (`@directus/license@0.6.1`):

| entitlement | Core |
| --- | --- |
| `seats` | 3 |
| `collections` | 25 активных (отсюда `COLLECTION_INACTIVE` с 12.4) |
| `flows` | 5 |
| `custom_permission_rules_enabled` | false |

На Core `PermissionsService.createOne/updateMany` отклоняет правило с ошибкой `RESOURCE_RESTRICTED`, если в нём есть хоть что-то из этого: фильтр строк, список полей вместо `*`, `validation`, `presets`. `readByQuery` молча отбрасывает такие правила, если они уже есть в базе (например, после даунгрейда). Проверено: seed с `assignee = $CURRENT_USER` упал на Core.

Места занимают только активные пользователи с политиками `app_access` или `admin_access`. API-only пользователи (мобильное приложение) места не занимают.

## Влияние на продукт

- Механизм «перечитать под accountability, невернувшееся — delete» работает на любом тарифе. Но на Core видимость всегда на уровне коллекции: построчного «вышла из видимости» там не бывает.
- Главный аргумент против PowerSync/ElectricSQL («уважаем права Directus») в полную силу работает только у лицензированных пользователей Directus. Это сужает аудиторию и должно быть в позиционировании.
- Лимит 25 коллекций на Core приходится учитывать в конфиге: `dirlocal_config` — это коллекция Directus и тоже занимает слот.

## Варианты

1. Целевая аудитория — лицензированные инсталляции. Тесты построчной видимости гоняем под лицензионным ключом (нужен dev/trial ключ).
2. Поддерживать и Core, и лицензию. Dev-seed совместим с Core, а построчные сценарии идут в отдельном seed или тест-наборе, который включается при наличии ключа.
3. Своя модель построчной видимости поверх Core (например, фильтр по полю-владельцу в конфиге dirlocal). Это противоречит ключевой идее «только права Directus»; не рекомендую.

Предлагаю вариант 2. Dev-seed уже сделан совместимым с Core. Нужен ли лицензионный ключ для интеграционных тестов, решает владелец.

Также проверить: `dirlocal_config` как коллекция Directus или как своя таблица с env/настройками — чтобы не тратить слот Core.
